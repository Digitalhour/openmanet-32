Set up your meshpoint

Choose a new root password, tell the meshpoint which OpenMANET network to join, and choose the Wi-Fi hotspot it will offer. It stays on this setup network until you finish.

1New root password

Replaces the default password. From now on you sign in to this page as root with it.

2Your OpenMANET network

Use the same mesh name and password as your OpenMANET nodes (in LuCI, the HaLow mesh interface's Mesh ID and key).

3This meshpoint's hotspot

Phones and laptops join this to reach the mesh and this page.

Setup saved

The meshpoint is restarting and joining . This setup network goes away.

  1. Wait about 20 seconds.
  2. Join the Wi-Fi network with the password you chose.
  3. Open http://192.168.4.1 and sign in as root with your new password to see the mesh and change settings.

Locked out? Hold the BOOT button for 5 seconds to erase the settings, root password included, and start setup again.
